# Guía anterior: Cloud Run / Cloud Tasks

Esta guía corresponde a una arquitectura anterior que utilizaba Cloud Run y Cloud Tasks. **No la sigas para la integración gratuita actual.**

La modalidad acordada para TerraCore utiliza:

- AppSheet como interfaz.
- Google Apps Script como puente.
- GitHub Actions para ejecutar Python y OpenCV.
- El mismo Google Sheets y Google Drive.

Consulta la guía vigente:

[APPSHEET_FREE_SETUP.md](APPSHEET_FREE_SETUP.md)

No necesitas crear un servicio Cloud Run, una cola Cloud Tasks ni habilitar facturación de Google Cloud para la modalidad gratuita.
